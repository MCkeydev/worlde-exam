# WordleGame 🟩🟨⬛

Un petit jeu Wordle développé avec Angular.

## 🚀 Lancer le projet

### 1. Installer Angular CLI

Assurez-vous d’avoir Node.js installé, puis installez Angular CLI globalement :

```bash
npm install -g @angular/cli
```

### 2. Démarrer l’application en mode développement

Depuis la racine du projet, lancez :

```bash
ng serve
```

L'application sera accessible à l'adresse [http://localhost:4200](http://localhost:4200).

---

## ✅ Lancer les tests & générer le coverage

Pour exécuter les tests avec un rapport de couverture :

```bash
ng test --code-coverage
```

Le rapport HTML de couverture se trouve à l’adresse suivante :

```
/coverage/index.html
```

Ouvrez-le dans votre navigateur pour consulter les résultats.
