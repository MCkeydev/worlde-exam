# Angular Wordle Game

This is an Angular implementation of Wordle with full UI/UX and comprehensive unit tests.

## Features

- **Basic:**  
  - 5-letter (or dynamic length) word validation  
  - Guess-checking logic with color feedback (green, yellow, gray)  
  - 6 attempts per game with game-over detection

- **Intermediate:**  
  - Dictionary of valid words  
  - Proper handling of duplicate letters  
  - Game statistics (wins, streak, average attempts)

- **Advanced:**  
  - Multiple game modes (Standard, Timed, Practice)  
  - Dynamic word lengths  
  - Score calculation system
